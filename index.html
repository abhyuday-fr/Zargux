How Zargux decides
  1. Attack

    Drop and run

    A binary is copied to a writable location such as /dev/shm or /tmp and executed. This is how real malware hides.

  2. Evidence

    Read origin and pressure

    /proc/<pid>/exe shows where the binary lives. /proc/pressure/cpu shows system load.

  3. Detection

    Classify by origin

    Writable-temp or deleted is High. Unpackaged elsewhere is Watch. Package-managed is Info.

  4. Response

    Log and display

    Each verdict is timestamped, saved, and shown here without anyone reading a terminal.
